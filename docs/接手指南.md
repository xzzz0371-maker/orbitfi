## 1. 项目概览

- **是什么**：以"风险分层 + 收益/风险/资本效率透明"为核心的 DeFi 借贷协议。存款人存 USDC 赚动态预估 Supply APY（随市场利率和资金利用率实时变化，不构成固定收益承诺）；借款人抵押 ETH、选五档 LTV（50/60/70/75/80%）借 USDC。
- **一句话**：用户自己选风险，系统实时给风险定价。
- **技术栈**：Solidity 0.8.24 + Foundry 1.8.1 + OpenZeppelin v5.7 + Chainlink + Solidity 原生测试；**前端已实现**（Next.js 14 + wagmi，连接 Sepolia，见 `frontend/README.md`）。
- **当前阶段**：合约 + 测试全部完成（126 用例）；Sepolia 部署脚本就绪，**链上广播待凭据**（RPC / 测试网钱包 / Etherscan Key）。

## 4. 合约架构与关键逻辑（读代码前必看）

### 4.1 会计模型（最重要）
- **USDC 存款**用份额记账：`shares = amount × 1e18 / supplyIndex`；取款 `amount = shares × supplyIndex / 1e18`。无 aToken。
- **利息累计**（`_accrue`）：按档位独立 `borrowIndexByTier[t]` 指数计息，`supplyIndex` 随总利息增长；**固定费率**：存款人 94% / 储备 `reserveFactor=4%` / Treasury `treasuryFactor=2%`；储备目标 = `totalBorrows × 3%`，超出自动溢出转 Treasury（`ReserveOverflowTransferred`，只从账面 `totalReserve` 划转，物理储备仅由坏账消耗；`totalBorrows=0` 不触发溢出）；`collectTreasury()` 提取 Treasury 并清零 `treasuryAccrued`。
- **债务计价（改动后）**：`debtWad = USDC数量 × USDC/USD价格`；抵押价值 `= ETH × ETH/USD价格`。LTV/HF/可借额全部基于美元价值。
- **核心不变式（每条资金路径后测试断言）**：`cash + totalBorrows == getTotalSupply() + totalReserve + treasuryAccrued`（USDC 单位，与价格无关）。

### 4.2 主要入口函数 — v1.0 · 2026-08-31
| 函数 | 权限 | 说明 |
|---|---|---|
| `supply(amount)` / `withdraw(shares)` | 无 | 存/取 USDC（share 单位取款）；`supply` 需 ≥ `MIN_SUPPLY=10 USDC` |
| `supplyCollateral()` (payable) / `withdrawCollateral(amount)` | 无 | 抵押/取回 ETH；`supplyCollateral` 需 ≥ `MIN_COLLATERAL=0.01 ETH` |
| `borrow(amount, tier)` / `repay(amount)` | 无 | 借（选档，需 ≥ `MIN_BORROW=100 USDC`）/还（type.max=全额） |
| `liquidate(target, debtToCover, minSeizeAmount)` | 无 | 清算（minSeize=0 不限制） |
| `handleBadDebt(target)` | 无 | 坏账即时传导（储备覆盖 + supplyIndex 降值） |
| `skimReserve()` / `accrue()` | 无 | 储备归集 / 手动计息 |
| `collectTreasury()` | 无 | Treasury 归集：`treasuryAccrued` 全部转给 `treasuryAddress` 并**清零**（非零地址方可调用） |

### 4.3 五档 LTV 与清算 — v1.0 · 2026-08-31
| 档 | 最大 LTV | 清算阈值 | 利率溢价 |
|---|---|---|---|
| 1 | 50% | 60% | 0 |
| 2 | 60% | 70% | +0.5% |
| 3 | 70% | 78% | +1.5% |
| 4 | 75% | 85% | +3% |
| 5 | 80% | 90% | +6% |

HF<1 可清算，closeFactor 50%，清算人按 105% 估值没收 ETH；一个用户同时只占一个档位（换档需先还清）。

### 4.4 利率模型与市场预设
`InterestRateModel`：`rate = base + slope1×util（≤kink1）+ slope2a×(util−kink1)（kink1<util≤kink2）+ slope2×(util−kink2)（>kink2）+ tierPremium`。NORMAL 为三段式（base 0.5%、slope1 4%（0-80%）、slope2a 25%（80-85%）、slope2 50%（>85%）、kink1 80%、kink2 85%、档位溢价 0/1/2/3/4.5%；目标 80%→3.7%、85%→4.95%、90%→7.45%、100%→12.45%）/ HIGH_VOL base=2%（两段）/ EXTREME base=5%（两段，RiskManager.maxBorrowTier=3 暂停高 LTV 档）。

### 4.5 Oracle 体系（三层）
1. **ChainlinkOracle**：连真实聚合器；stale 超 1h revert；偏差超 **maxDeviation（默认 30%，范围 10%~200%）** 不 revert，`updatePrice` 触发 `PriceAnomalyDetected` 并标记 `priceAnomalous[asset]`；fallback（缓存价，限 1 天）；PAUSER 可 pause。
2. **SwitchableOracle**：主源=ChainlinkOracle；PAUSER 可 `enableSettable()`/`disableSettable()` 切到"管理员可设价"模式（用于测试网清算演示）；可设价模式 `isPriceAnomalous` 返回 false。
3. **LendingPool 消费侧**：`_oracleAnomalous()` 检查 ETH/USDC 标记；**异常时 `borrow`/`supplyCollateral` revert，`repay`/`withdraw`/`liquidate` 正常**。

### 4.6 坏账（即时传导，不挂账）
抵押归零仍有债 → `handleBadDebt`（任何人可调）先由风险储备（第一损失缓冲）覆盖可覆盖部分，未覆盖部分即时降低 `supplyIndex`（所有存款人按份额承担，类似基金净值下跌），仓位一次性清零。事件 `BadDebtRealized(user, badDebtAmount, coveredByReserve, lossToDepositors, oldSupplyIndex, newSupplyIndex)`。**无 `settleBadDebt`、无 `totalBadDebt`**；存款本金可能因坏账而受损。坏账消耗储备后储备低于目标，溢出机制停止，重新开始积累。

### 4.7 RiskEngine
只输出 LOW/MEDIUM/HIGH/EXTREME 建议，**不触碰资金**。`calculateRiskLevelAuto(ltv, lt)` 从池直读 Utilization/流动性 + 引擎波动率采样；手动版 `getRiskLevel(vol,util,ltv,lt,liq)` 保留供测试。

## 7. 安全机制与已知风险

**已实现**：ReentrancyGuard + `call{value}` 转账；CEI；份额/指数记账 + 取整对协议有利；USDC 脱锚计价；Oracle stale/偏差/fallback/pause + 异常禁新增敞口；暂停开关；事件全量；**坏账即时传导给存款人**（超出储备缓冲部分即时降低 `supplyIndex`，存款本金可能受损）；**储备溢出自动转 Treasury**（超过 `totalBorrows × 3%` 自动转出，储备不无限膨胀）；前端须按完整文档 §1.6 展示风险披露。

3. 偏差容忍副作用：极端跳价以异常价执行（为保清算）→ 事件监控 + PAUSER 暂停兜底。
4. 未经外部安全审计（阶段 8）。

## 9. 设计决策记录（Q&A）

1. **ETH 转账**：原生 ETH，`call{value}`（`_safeSendEth`），失败 revert；不受 2300 gas；重入被 Guard 拦截。
2. **ReentrancyGuard**：全部状态函数。
3. **minAmount**：V1 无 AMM 无滑点；清算有 `minSeizeAmount`（0=不限）。
4. **70%→78% 清算阈值**：有意设计，可配。
5. **USDC 计价**：债务=USDC×USDC/USD 价格；USDC=1 时与旧行为一致；溢价抬 LTV、脱锚降 LTV（UsdcPeg 5 场景覆盖）。
6. **Oracle 偏差**：不 revert、事件化、异常禁新增敞口；PAUSER 可暂停。
7. **RiskEngine**：纯建议；Auto 从池直读；liquidity 有 0~1 校验。
8. **无绕过 oracle 校验的读价路径**。

## 11. 常见问题排查 — v1.0 · 2026-08-31

| 现象 | 原因 | 处理 |
|---|---|---|
| `InsufficientFunds` | 钱包无测试网 ETH | faucet 领 ETH |
| `stale price` | 喂价超 1h 未更新 | 等更新或换 feed |
| `price anomalous` | 偏差>30% 被标记 | 等价格回归；repay/withdraw/liquidate 不受限 |
| `insufficient liquidity` | 池现金不足 | 增加存款 |
| `ltv too high` | 借款超档位上限 | 用 `maxBorrowable` |
| `price not set` | SwitchableOracle 可设价模式漏设价 | 为 ETH 和 USDC 都 `setPrice` |
| `oracle paused` | 被 PAUSER 暂停 | `unpause()` |

| `stack too deep`（coverage） | 覆盖率禁 via_ir | 加 `--ir-minimum` |
