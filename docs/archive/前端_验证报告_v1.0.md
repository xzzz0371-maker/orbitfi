## 4. 验证结果

- `npm run build` ✅ 编译通过、TypeScript 0 错误（Next.js 14.2.35）。
- `npm run dev` 启动后 5 个路由均返回 **200**（`/`、`/dashboard`、`/stress-test`、`/history`、`/about`）。
- 首页内容断言：`ZZZ Lend`、`Choose Your Risk`、`Estimated, not guaranteed`、`Deposits are not guaranteed`、`Sepolia` 均存在 ✅。
- 最小金额限制（MIN_SUPPLY=10 / MIN_BORROW=100 / MIN_COLLATERAL=0.01）在前端输入校验 + 按钮禁用 ✅。

## 5. 遇到的问题（记录）

1. **合约函数名与任务预期不符**（前端按真实 ABI 实现，已在 `frontend/README.md` 记录）：
   `getSupplyAPY`→`getSupplyAPR`、`getUserDebt`→`getDebt`、`getCash`→`cash`、`totalBorrows`→`getTotalBorrows`、
   `getUserShares/getUserCollateral`→`positions/getUserPosition`、`getEthPrice/getUsdcPrice`→`SwitchableOracle.getAssetPrice`、
   `isSettable`→`useSettablePrice`、`borrow/maxBorrowable` tier 为 `uint256`、`withdraw` 传份额（`usdc6×1e18/supplyIndex`）。
2. **构建依赖**：`wagmi/connectors` 桶引入 coinbase/base/metamask SDK，需补装 `@x402/core/@x402/evm/@x402/svm`、`pino-pretty`，并在 `next.config.mjs` 用 webpack 别名把 react-native 包替换为 `stubs/` 桩。
3. **USDC/USD feed 在 Sepolia 可能 stale**：前端读 ETH/USD，USDC 价回退默认 1、ETH 回退 `FALLBACK_ETH_PRICE`（2400）——仅展示层兜底。
4. 浏览器端 MetaMask 实际签名/交易需本机人工验证（写路径已接好）。
