## P0：F1 — repay/liquidate 取整下溢（已修复）

**问题**：`_getDebt6` 向上取整，极小借款（borrowNorm 与 1 个 USDC 微单位同量级）计息后 `debt6` 进位到 `borrowNorm+1`，而 `repay`/`liquidate` 的 `normReduction = ceil(debt6×WAD/index)` 同样进位到 `borrowNorm+1` → `pos.borrowNorm -= normReduction` **下溢 revert**，仓位被锁。`handleBadDebt` 原有兜底，`repay`/`liquidate` 缺失。

**修复**（`src/LendingPool.sol`）：
```solidity
// repay()
uint256 normReduction = repayAmount * WAD / borrowIndexByTier[pos.tier];
if (normReduction > pos.borrowNorm) normReduction = pos.borrowNorm; // 防取整下溢（F1）

// liquidate()
uint256 normReduction = _mulDivUp(cover6, WAD, borrowIndexByTier[pos.tier]);
if (normReduction > pos.borrowNorm) normReduction = pos.borrowNorm; // 防取整下溢（F1）
```

**回归测试**：`test_F1_MicroBorrowFullRepayWorks`（借 1 微计息后 `repay(type.max)` 不 revert、清债）、`test_F1_MicroBorrowLiquidationWorks`（closeFactor=100% 全额覆盖不 revert）、`test_F1_NormalBorrowUnaffected`（正常规模不受影响）。

## P1：F3 — SwitchableOracle.setPrice 无校验（已修复）

**问题**：`setPrice` 仅校验 `asset != 0`，可设 `price=0`（DoS）或任意极大价（操纵抵押/债务估值）。

**修复**（`src/oracle/SwitchableOracle.sol`）：
```solidity
require(price > 0, "price must be > 0");
require(price >= 1e2 && price <= 1e14, "price out of range"); // $1e-6 ~ $1e6（8 位小数）
```

**回归测试**：`test_F3_SetPriceZeroReverts` / `SetPriceAboveUpperBoundReverts` / `SetPriceBelowLowerBoundReverts` / `NormalPricesOk`。

## P1：F4 — 模块 setter 缺零地址校验（已修复）

## P2：F2 — 坏账超额损失破坏守恒（已修复）

**问题**：`handleBadDebt` 当 `loss ≥ supply` 时把 `supplyIndex` 归零，但**超额部分（loss − supply）无处吸收**，资金守恒被破坏；无存款人（`supply==0`）时同样不守恒。

**说明**：审计推荐方案是 `require(supplyBefore > 0)` 直接 revert。但该方案在 `loss > supply > 0`（利用率 100%、单笔坏账超过净资产，可达）时**仍会破坏守恒**，不满足"守恒始终成立"的硬性要求，故采用**级联吸收**方案：

**修复**（`src/LendingPool.sol::handleBadDebt`）——损失吸收顺序：
1. **存款人**：`supplyIndex` 按份额承担，最多承担全部净资产（可归零）；
2. **账面储备** `totalReserve`（未 skim 的第一损失缓冲）；
3. **Treasury** `treasuryAccrued`（协议收入兜底）。

由不变式 `cash+borrows = supply+reserve+treasury` 可得 `loss ≤ borrows ≤ supply+reserve+treasury`，故损失**必可被完全吸收**，守恒恒成立。主路径（`loss < supply`）行为与修复前完全一致。

**回归测试**：`test_F2_ExcessLossConservationHolds`（100% 利用率借满 5 年后坏账 → supplyIndex 归零且守恒成立）、`test_F2_NoDepositorsConservationHolds`（无存款人时再出坏账 → 由储备/Treasury 吸收，守恒成立）。

## P2：F5 — ChainlinkOracle 偏差标记 + fallback（已修复 + 文档化）

**问题**：① `priceAnomalous` 只在 `updatePrice()` 刷新，无人调用则 `_oracleAnomalous()` 不拦截偏差价；② fallback 直接返回缓存价。

**修复**（`src/oracle/ChainlinkOracle.sol`）：
- 新增 `lastValidPrice`（最近一次"正常"采样价）作为**稳定偏差基准**，`updatePrice` 仅在非偏差时更新；
- `isPriceAnomalous()` 改为**实时**读取最新价并与 `lastValidPrice` 内联计算偏差（不再依赖 updatePrice 先被调用；正常模式下 feed stale 同样 revert，fail-closed）；fallback 模式返回缓存标记。
- `_getFallbackPrice` 文档化取舍：fallback 无法读实时 feed 时不做偏差校验，靠 `fallbackMaxAge` 限时；长中断由 PAUSER 人工介入。

**回归测试**：`test_F5_LiveDeviationWithoutUpdatePrice`（feed 跳变 -50% 不调 updatePrice → `isPriceAnomalous` 为 true，borrow/supplyCollateral revert "price anomalous"）、`test_F5_FallbackUsesCachedPriceAndFlag`（fallback 冻结缓存价、用缓存标记）。

## P2：F9 — oracle 暂停阻断清算（文档化取舍 + 测试固化）

**取舍**：oracle 被暂停时读价 revert → 清算一并暂停。宁可不清算，也不用可能错误/暂停中的价格清算；PAUSER 暂停 oracle 前应确认无待清算仓位。已在 `LendingPool.liquidate` natspec 与文档中说明。

**回归测试**：`test_F9_OraclePauseBlocksLiquidation`（暂停 → liquidate revert "oracle paused"；unpause 后恢复成功）。

## 补充：最小金额限制（dust limit，v1.2 · 2026-08-31）

为防尘埃仓位/微额操作，新增 3 个常量并在入口函数强制校验（`src/LendingPool.sol`）：

```solidity
uint256 public constant MIN_SUPPLY = 10e6;        // 最小存款 10 USDC（6位小数）
uint256 public constant MIN_BORROW = 100e6;       // 最小借款 100 USDC
uint256 public constant MIN_COLLATERAL = 0.01 ether; // 最小抵押 0.01 ETH
```

**实施**：
- `supply(amount)`：`require(amount >= MIN_SUPPLY, "amount below min")`
- `borrow(amount, tier)`：`require(amount >= MIN_BORROW, "amount below min")`
- `supplyCollateral()`：`require(msg.value >= MIN_COLLATERAL, "value below min")`

**影响**：
- **F1 取整下溢结构性不可达**：最小借款 100 USDC 后，债务进位（≤1 微单位）相对借款量可忽略，`normReduction` 不再可能超过 `borrowNorm`；F1 封顶逻辑保留作纵深防御。
- **Precision 微额用例调整**：`Precision.t.sol` 中原 1 微 USDC 存/借用例改为使用最小金额（`MIN_SUPPLY`/`MIN_BORROW`）并重命名。
- **回归测试**（`SecurityFixes.t.sol`）：`test_DustLimit_SupplyBelowMinReverts` / `BorrowBelowMinReverts` / `CollateralBelowMinReverts` / `SupplyAndCollateralMinWork` / `BorrowMinWorks`。
