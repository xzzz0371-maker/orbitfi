### 第 1 步：给部署者钱包转 gas 费　⏱ 1 分钟

从你的钱包转 **0.001 ETH**（**Base 网络**）到：

```
0xcAd3577EaC3d385Bc8FB39Bd75062153ba3a9b43
```

> ⚠️ **转账前核对这个地址。** 它由 `go-live check` 从你的私钥现场派生，是权威值。
> 想再确认一次可以跑（只打印地址，不打印私钥）：
>
> ```powershell
> cd C:\Users\Administrator\Desktop\test_opencode
> $c = [System.IO.File]::ReadAllText("contracts\.env.mainnet", [System.Text.Encoding]::UTF8)
> $k = ($c -split "`n" | Where-Object { $_ -match "^PRIVATE_KEY=" })[0] -replace "^PRIVATE_KEY=", ""
> cast wallet address --private-key $k.Trim()
> ```

为什么是 0.001：实测整套部署只要 **0.00013 ETH**，0.001 能覆盖 8 次，留足 gas 波动余量。

### 第 2 步：广播部署　⏱ 1 分钟

```powershell
cd C:\Users\Administrator\Desktop\test_opencode
node scripts/go-live.mjs broadcast
```

它会依次：

1. 查部署者余额（不够会拦住，不会白烧 gas）
2. **打印 admin / treasury / pauser 三个地址让你确认**
3. 等你输入 `y`
4. 广播 → 部署 → 自动跑 31 项链上核验

**输入 `y` 之前认真看一眼那三个地址。** 合约没有代理、不可升级，部署错了只能整组重来。

## 五、出问题怎么办

| 情况 | 处理 |
|---|---|
| `broadcast` 报余额不足 | 确认转账已到账（Base 出块快，通常几秒） |
| 广播中途失败 | 失败的交易也烧 gas，但金额极小；把完整输出发我 |
| 核验 31 项有 FAIL | **不要继续下一步**，发我 |
| gas 价格突然飙升 | 等一下再跑，Base 常态 < 0.05 gwei |
| 想放弃这次部署 | 合约无代理不可升级，只能整组重新部署到新地址；已部署的旧池归档 |

**任何报错都把完整输出发我**，脚本已经把诊断信息打全了。
