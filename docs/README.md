## 三、维护约定

- **文档命名**：`主题_YYYY-MM-DD.md`，日期为产出日
- **版本钉死**：审查/测试报告一经产出不再修改内容，后续变化写进新文档，避免"文档看起来更新了但结论还是旧的"
- **归档规则**：被取代的文档移入 `archive/`，**不删除**（审计与尽调需要证据链）
- **引用路径**：跨目录引用写完整路径 —— 根目录文档写 `docs/<文件名>`，归档文档写 `docs/archive/<文件名>`
- 新增文档后，请在上方对应表格补一行
